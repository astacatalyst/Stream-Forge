1. Objective

The objective of Week 1 is to establish the Kafka streaming foundation for Stream Forge. A Python-based producer generates mock IoT truck telemetry and sends it to a Kafka topic, while a Python consumer receives and displays the streaming data.

2. Technologies Used
Python
Apache Kafka
kafka-python
Docker / Docker Desktop
VS Code
Git & GitHub

3. Kafka Configuration
Kafka Broker: localhost:9092
Topic: stream-events
Consumer Group: stream-forge-consumer

4. Mock Truck Telemetry

The producer continuously generates simulated truck telemetry containing:

Truck ID
Temperature
Timestamp

Example:

Truck ID: TRUCK-1024
Temperature: 31.72 °C
Timestamp: 2026-08-15T17:10:23+00:00

The producer sends these events continuously to the stream-events Kafka topic.

5. Kafka Producer

The Python producer uses the kafka-python library to connect to Kafka and publish telemetry messages.

The telemetry data is converted to JSON before being sent to Kafka.

Flow:

Mock Truck Data
      ↓
Python Producer
      ↓
Kafka Topic: stream-events

6. Kafka Consumer

The Python consumer subscribes to the stream-events topic and continuously receives the telemetry generated by the producer.

It deserializes the JSON messages and displays:

Truck ID
Temperature
Timestamp
Kafka Topic
Partition
Offset

Flow:

Kafka Topic
     ↓
Python Consumer
     ↓
Telemetry Output

7. End-to-End Flow
Mock IoT Truck Telemetry
          ↓
    Kafka Producer
          ↓
   Kafka: stream-events
          ↓
    Kafka Consumer
          ↓
   Continuous Output


8. Testing

The implementation was tested locally using Docker.

Kafka was started using:

docker start kafka

The consumer was started using:

python streaming/consumer.py

The producer was started in another terminal using:

python streaming/producer.py

The producer successfully generated continuous mock telemetry, and the consumer successfully received and displayed the messages.

9. Week 1 Outcome

Week 1 successfully established the Kafka foundation for Stream Forge. The Producer → Kafka → Consumer pipeline was implemented and tested using continuous mock IoT truck telemetry.

10. Next Week

Week 2 will focus on stream processing, including filtering, mapping, and implementing time-based windows for the incoming truck telemetry.
